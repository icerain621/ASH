# W0 Harden Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改产品边界的前提下，完成 W0 硬化：OpenAPI 卫生、Chat 审批席位/空态/模式对齐原型、审批预设（once/会话/策略）、MCP 注册工具可 HTTP 执行且 fail-closed。

**Architecture:** 复用现有 `permissionMode` 枚举与 `SpacePolicyPack.BodyJSON` 扩展；gate 经 session `actions` / run approve 扩展动作码；MCP 执行走已有 `toolbus` `mcp.call`，经登记表解析 endpoint，并挂入 EW04 审批预设。

**Tech Stack:** Go (Gin, GORM) · React/Vite · OpenAPI/swag · vitest · 现有 AgentChatShell / ChatSeats / IntentBar / McpToolsPanel

**Board:** [`doc/plan/sprint-ew-w0-harden.md`](../../doc/plan/sprint-ew-w0-harden.md)  
**Inventory:** [`doc/plan/ash-feature-inventory.md`](../../doc/plan/ash-feature-inventory.md)

## Global Constraints

- 默认 fail-closed：新建会话 `permissionMode=read-only`；禁止 YOLO 默认
- 不改 `permissionMode` 后端枚举值（仍为 `read-only|workspace-write|full`）；仅 UX 映射 ask/auto/full
- 不做 Cordis、Hooks、Steer/Queue、会话树 fork（W1+）
- Commit 说明中文；不提交 `doc/evidence/device-session-smoke-latest.md`、无关 archify 产物
- 每 Sprint 结束：对应测试绿 + `make openapi-check`（涉及 API 时）
