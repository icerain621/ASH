# Design: v2.7 Evolution Plane (DX25–DX30)

> Status: **approved / frozen** (2026-09-06; B1–B8 confirmed; DX25–DX30 delivered; scope frozen via DX30)  
> Version lane: **v2.7 frozen** (DX25–DX30; v2.6 frozen DX20–DX24)  
> Scope: [`doc/plan/v2.7-release-scope.md`](../../doc/plan/v2.7-release-scope.md)

## Goal

Ship lean MVPs for the four post-v2.6 asks (LSP, E2B, real embed, marketplace/AA) **plus** hardening leftovers (C), without expanding into public market / Active-Active / E2B cloud / full LSP.

| Sprint | Theme | One-liner |
|--------|-------|-----------|
| **DX25** | Vector harden (C) | `prefer=vector`; Qdrant create-if-missing; merge tests |
| **DX26** | Real Embedder | OpenAI-compat HTTP; Hash fallback |
| **DX27** | Sandbox evidence | Linux Landlock+seccomp e2e checklist/CI; E2B Out |
| **DX28** | Org skill catalog + UI | Signed catalog list → verify/install; Automation polish |
| **DX29** | Thin LSP (required) | gopls/tsserver one-shot symbols; `source=lsp`; strengthen LSP path |
| **DX30** | Freeze | `v2.7-release-scope` + `make v2.7-signoff` |

Tag `v2.7.0` remains **manual**.

## Non-goals

- Full LSP language-server product (hover, defs/refs, diagnostics stream)
- E2B / remote microVM as default or billed dependency
- Public Skill Marketplace, ratings, billing, CDN
- Active-Active multi-region
- Chroma/Milvus; embedding as hard release blocker
- Cloud RDS / GitHub·ExecGo live as release blockers

---

## DX25 — Vector harden

1. Extend `prefer` / query path to honor `vector` (and document Profile retrieval honesty).
2. Qdrant: create collection if missing (idempotent).
3. Package tests: vector-only merge / empty-vector degrade.
4. Extend `rag-vector-smoke`.

## DX26 — Real Embedder

1. `OpenAICompatEmbedder` (or similar) behind existing `Embedder` interface.
2. Env: `ASH_EMBED_BASE_URL` / `ASH_EMBED_API_KEY` / `ASH_EMBED_MODEL` (names finalize in task).
3. Default remains Hash when unset; never fail Index hard on embed errors (best-effort as today).
4. Optional live smoke behind env flag.

## DX27 — Sandbox evidence (not E2B)

1. Linux CI / checklist proving Landlock FS deny + seccomp deny-list behavior.
2. Evidence under `doc/evidence/` + `sandbox-smoke` optional e2e segment.
3. Document Executor extension point for future remote backends — **no E2B client**.

## DX28 — Org skill catalog + UI

1. Catalog format: JSON list of `{name,version,publisher,url,digest}` + HMAC or publisher allowlist.
2. API: list catalog + install-from-catalog (reuse pack verify/install).
3. Automation: verify dry-run button, clearer errors, installed hint.
4. Prefer filesystem/HTTP — **no new table** unless audit requires.

## DX29 — Thin LSP (required · B8)

1. `LSPIndexer` implementing `SymbolIndexer`: one-shot `gopls` and/or `typescript-language-server` (documentSymbol / workspace/symbol style) — **no resident daemon**.
2. Persist `rag_symbols.source=lsp`; prefer order via `ASH_RAG_SYMBOL_INDEXER=lsp` or auto after treesitter when tools on PATH.
3. Fallback per file: treesitter → ctags → regex (existing rebuild path).
4. Smoke + docs; full hover/defs/refs remain Out → v2.8.

## DX30 — Freeze

- Freeze scope; `scripts/v27-signoff-gate.sh`; wire `scope-freeze-gate`; watermarks; no auto tag.
