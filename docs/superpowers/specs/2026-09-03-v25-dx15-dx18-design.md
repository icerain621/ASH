# Design: v2.5 Evolution Plane (DX15–DX18)

> Status: approved for planning (2026-09-03)  
> Version lane: **v2.5 draft** (v2.4 frozen DX12–DX14)  
> Related: Waker · RAG Hybrid · Sandbox · `doc/plan/v2.5-release-scope.md`

## Goal

Deliver four incremental capabilities on the v2.4 baseline, then freeze **v2.5** (DX19 signoff):

| Sprint | Theme | One-liner |
|--------|-------|-----------|
| **DX15** | Waker probe auto-seed | Seed `doctor_subset` / `kpi_drift` duties; console one-click enable; status hints |
| **DX16** | ctags symbol indexer | Pluggable symbol backend; ctags subprocess with regex fallback |
| **DX17** | Vector retrieval POC | Qdrant lane + stub embedder; FTS/hybrid degrade path |
| **DX18** | Landlock sandbox POC | Linux Landlock executor; Docker/process fallback unchanged |

Tag `v2.5.0` remains **manual** after human sign-off (DX19).

## Non-goals (v2.5 Out)

- Skill Marketplace, multi-region, billing
- Production-default auto cancel (DX7 gates unchanged)
- Real embedding API as hard dependency (stub embedder OK for POC)
- E2B / full container orchestration
- Cloud RDS / GitHub·ExecGo live as release blockers
- Breaking v2.3 Hybrid or v2.4 Waker APIs (extensions only)

## DX15 — Waker probe auto-seed (方案 C)

### Problem

DX13 方案 A deliberately **did not** seed `doctor_subset` / `kpi_drift`. Ops must call `Ensure*` manually. DX15 closes the gap while keeping probes **disabled by default**.

### Behavior

1. `Status()` and `StartBackground()` call `EnsureDoctorSubsetDuty(space, false)` and `EnsureKPIDriftDuty(space, false)` after `EnsureStaleRunDuty` — same spaces as stale_run (`local` + `knownSpaces()`).
2. Rows exist with `enabled=false`; scheduler skips them until enabled.
3. **Enable paths** (any one):
   - `POST /waker/duties/{id}/enable` body `{"enabled":true}` (new)
   - Observability UI toggle per duty
   - Env `ASH_WAKER_ENABLE_PROBES=1` → seed with `enabled=true` (server boot only)
4. `StatusResponse` adds `probesAvailable: true` and per-duty `seeded: true` when row exists.
5. When recent duty_run has `flagged>0`, queue already surfaces items; Status adds `alertCount` (sum of open queue probe findings).

### Schema

**No new tables** (SQL 29 / RLS 50 unchanged).

### Tests / gates

- Replace `TestStatusDoesNotAutoSeedDoctorOrKPI` → `TestStatusAutoSeedsProbesDisabled`
- `make waker-smoke` extended for enable API + status fields

## DX16 — ctags symbol indexer (方案 B)

### Problem

DX9 regex extraction misses cross-language symbols. ctags is the lightest external indexer without LSP complexity.

### Architecture

```
RebuildSymbols
  ├─ SymbolIndexer interface
  │    ├─ RegexIndexer (existing matchSymbolLine)
  │    └─ CtagsIndexer (subprocess: ctags -x --fields=+n -f -)
  └─ upsert rag_symbols (source: regex|ctags)
```

1. `ASH_RAG_CTAGS=1` or auto-detect `ctags`/`universal-ctags` on PATH → prefer ctags.
2. If ctags fails or unavailable → **regex fallback** (no 5xx).
3. `RebuildSymbolsResponse` adds `symbolSource: "ctags"|"regex"`.
4. SQL **30**: `rag_symbols.source TEXT NOT NULL DEFAULT 'regex'` (SQLite + Postgres).

### Non-goals

- LSP / tree-sitter this sprint
- Background cron rebuild

### Tests / gates

- `make rag-hybrid-smoke` + unit tests with fake ctags fixture script
- Doctor: optional case for ctags availability (warn, not fail on Windows)

## DX17 — Vector retrieval POC (方案 A)

### Problem

FTS + Hybrid RRF is sufficient for MVP; vector lane proves pluggable dense retrieval without making it the main path.

### Architecture

```
Index / embed job ──► Embedder (stub hash POC) ──► Qdrant collection ash_{space}
Query ──► existing lanes + vector lane ──► rrfMerge (4th lane "vector")
```

1. **Embedder interface**: `Embed(texts []string) ([][]float32, error)` — default `HashEmbedder` (deterministic, no network).
2. **Vector store**: Qdrant HTTP client (`ASH_QDRANT_URL`, default `http://127.0.0.1:6333`); skip lane when unreachable.
3. SQL **31**: `rag_vector_refs` — `(space_id, repo_root, chunk_id, point_id, updated_at)` + RLS (+2 policies → RLS **52**).
4. `POST /rag/index` optional `embed=true`; `Query` adds vector lane when Qdrant + refs exist.
5. `retrievalMode` may return `hybrid+vector`; profile adds `vectorAvailable`, `vectorPointCount`.
6. `make rag-vector-smoke` (Qdrant optional; unit tests mock HTTP).

### Degrade

Qdrant down → omit vector lane; same as empty hybrid tables today.

### Non-goals

- Chroma/Milvus adapters
- Production embedding provider requirement

## DX18 — Landlock sandbox POC (方案 B)

### Problem

Docker/process jails are coarse. Landlock gives Linux kernel-level filesystem sandbox for `isolated` mode without full containers.

### Architecture

```
DefaultRouter.Route
  isolated + ASH_SANDBOX_LANDLOCK=1 + landlock.Available()
    → executor "landlock" (new internal/sandbox/landlock/)
  else existing docker/process chain
```

1. Implement `sandbox.Executor` for Landlock (Linux only; build tags `linux`).
2. `landlock.Available()` probes kernel ≥ 5.13 + `prctl` support.
3. Windows/macOS: unchanged fallback (process path jail / Docker).
4. Doctor **M4-SBX-04**: report `landlockAvailable` (pass on Linux with support, skip elsewhere).
5. `make sandbox-smoke` optional `ASH_SANDBOX_LANDLOCK=1` segment (Linux CI job).

### Non-goals

- E2B, seccomp profiles beyond minimal Landlock FS rules
- Replacing Docker as default isolated executor
