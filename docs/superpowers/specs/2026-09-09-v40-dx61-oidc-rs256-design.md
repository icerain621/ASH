# v4.0 DX61 — OIDC RS256 / JWKS

> Status: **done** (2026-09-09)  
> Program: A Auth harden · [`doc/plan/v4.0-release-scope.md`](../../../doc/plan/v4.0-release-scope.md)

## Goals

- Validate `id_token` with **RS256** using IdP `jwks_uri` from OIDC discovery
- Keep **HS256** path for mock IdPs / existing tests
- Cache discovery + JWKS in-process (no new tables)

## Non-goals

- Refresh / jti（DX62–DX63）  
- SAML / multi-IdP  
- Force-default OIDC  

## Approach

- Extend discovery with `jwks_uri`
- Dispatch on JWT header `alg`: HS256 → client_secret HMAC；RS256 → JWKS RSA (`kid` match or first `kty=RSA`)
- Stdlib only (`crypto/rsa`); no new JWT library

## Verification

```bash
go test ./internal/idp/ ./internal/api/ -run 'OIDC|ClientExchange|RS256' -count=1
```
