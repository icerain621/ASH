# ASH MVP 发布检查清单（可勾选）

## 1. 需求与范围确认
- [ ] 本次发布目标、范围、不包含范围已在评审中确认
- [ ] 需求变更已冻结（仅允许 P0 缺陷修复）
- [ ] PRD、API、数据库文档已同步至最新版本

## 2. 开发完成度
- [ ] P0 功能全部开发完成
- [ ] 前后端联调完成，主链路可用
- [ ] 异常路径（失败/重试/取消）已验证
- [ ] 高风险动作审批流程可用

## 3. 测试与质量
- [ ] 后端单元测试通过（`go test ./...`）
- [ ] 前端 lint 与核心测试通过（`pnpm lint` / `pnpm test`）
- [ ] 集成测试通过（任务创建 -> 启动 -> 执行 -> 输出）
- [ ] 回归测试通过（历史功能无回归）
- [ ] 严重缺陷（P0/P1）为 0

## 4. 性能与稳定性
- [ ] 关键接口响应满足基线要求
- [ ] 任务并发执行压测达标
- [ ] SSE 连接稳定、断线可重连
- [ ] 队列积压与消费速率在可控范围

## 5. 安全与权限
- [ ] JWT、RBAC 配置正确
- [ ] 高风险接口权限校验通过
- [ ] 审计日志记录完整
- [ ] 默认密钥/测试账号已移除或替换

## 6. 数据与迁移
- [ ] 数据库迁移脚本在 staging 成功执行
- [ ] 新增表、索引、约束验证通过
- [ ] 关键数据已备份
- [ ] 回滚脚本（DDL/DML）已准备并演练

## 7. 可观测与告警
- [ ] 日志字段包含 `traceId/taskId/runId/userId`
- [ ] 核心指标已接入（成功率、时延、失败率、队列积压）
- [ ] 告警规则已配置并测试（接口错误率、队列阻塞、DB 异常）
- [ ] 仪表盘可用于上线后实时观察

## 8. 发布准备
- [ ] 发布窗口与值班人员已确认
- [ ] 版本号与变更说明（Changelog）已生成
- [ ] 配置文件与环境变量已核对
- [ ] API 文档与使用说明已同步

## 9. 灰度与回滚
- [ ] 灰度策略已配置（按空间/项目/用户比例）
- [ ] 灰度观察指标与阈值已定义
- [ ] 回滚触发条件明确（错误率、失败率、性能退化）
- [ ] 回滚流程演练完成并记录耗时

## 10. 上线后验证（T+0 / T+1）
- [ ] T+0：核心路径冒烟通过
- [ ] T+0：无严重告警，错误率在阈值内
- [ ] T+1：关键指标达标（采纳率/成功率/时延）
- [ ] T+1：收集首批用户反馈并形成修复计划
