## 1. 发布目标

在已有 `ash session rpc`（LF-JSON）与 Waker / 沙箱路由之上，交付 **可 CI 嵌入的 RPC 烟测与 Doctor 探针**、**通知适配器缝（零 IM 通道）**，以及 **Harness/探测上的 Backend 枚举可读**。不引入 Hermes 全 IM、不默认 YOLO、不新开调度微服务。  
On the existing `ash session rpc` and Waker/sandbox router, ship CI-usable RPC smoke + Doctor probe, a notifier adapter seam with zero IM channels, and a readable Backend enum on harness/probes. No Hermes IM matrix, no YOLO default, no new scheduler microservice.

达到可打 **`v6.3.0`** 标签的功能与文档水位。  
Reach the feature and doc watermark for a manual **`v6.3.0`** tag.

做法 / Approach：A。产品化已有 RPC 包；Cron 只接 Notifier 接口 + 本地/日志适配器；Backend 枚举投影现有 executor，不新开远程厂商。  
Approach A: productize the existing RPC package; Cron only adds a Notifier seam + local/log adapter; Backend enum projects existing executors — no new remote vendors.

No Hermes IM matrix, no new remote vendors, and no auto-tag.
