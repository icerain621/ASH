## 1. 发布目标

把业已落地的 **可审计执行扩展点 + 会话语义投影 + Skills/MCP/Hooks 闭环 + 子代理谱系与记忆厚审深链**（inventory W0–W12）收成可签字、可打 **`v6.0.0`** 的水位。不引入 Hermes 全 IM、不默认 YOLO、不重开 Cordis / dsh web，不自动打 tag。  
Freeze the already-shipped auditable execution surface, session semantics, Skills/MCP/Hooks loop, lineage, and memory thick-review deep links (inventory W0–W12) into a signable **`v6.0.0`** watermark. No Hermes full IM matrix, no YOLO default, no Cordis/dsh web reboot, no auto-tag.

做法 / Approach：A。冻结现有 EW 吸收交付与 `make v6-signoff`；v6.3+（RPC 嵌入 / Cron 通知 / Backend 枚举）另开代际。  
Approach A: freeze the current EW absorb delivery and `make v6-signoff`; leave v6.3+ (RPC embed / Cron notifier / Backend enum) for a later generation.
