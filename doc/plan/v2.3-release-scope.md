## 1. 发布目标

在 v2.2 Waker 运维底座上交付 **RAG Hybrid 符号索引（路径 + 符号 + 文本 RRF 融合）**，达到可评审 **`v2.3.0`** 标签的功能与文档水位（向量库主路径与 ctags 仍为 Out）。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Hybrid Schema | 表 `rag_path_entries` / `rag_symbols`（SQL **28** / RLS **48**）（**DX9**） |
| RebuildSymbols | `POST /rag/symbols/rebuild`；扫盘 upsert + stale 清理；与 chunk Index 解耦（**DX9**） |
| Hybrid Query | path/symbol/text RRF（k=60）；空表回退 FTS/chunk；Profile hybrid 字段（**DX9**） |
| 烟测 / 草案 | `make rag-hybrid-smoke`；本文件 §1–§6 草案（**DX9**） |

## 3. 不包含范围（本版本 Out）

- 向量库主路径（Chroma/Qdrant 等）
- ctags / LSP 外部符号解析依赖
- Skill Marketplace、知识图谱
- v2.2 已冻结项的 scope 变更（Waker cancel 策略等）
- 云 RDS 生产切流签字（H-01～H-03）

## 4. 变更冻结规则

- **本文件仍为草案**；冻结前可接受范围调整与 P0 功能补齐
- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）
- 破坏性 API 须 OpenAPI + `make openapi-check`
- 打 **`v2.3.0` tag** 前须将本文件标记 **已冻结** 并完成签字门禁（待后续 Sprint 定义 `make v2.3-signoff`）
