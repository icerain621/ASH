## 1. 发布目标

在已有组织技能目录（`.ash/skill-catalog.json`，非公网市场）和单区域标识（`ASH_REGION`）之上，交付 **私有目录可辨认、远程包源 fail-closed**，以及 **多区域明确关闭** 的探测。不计费、不做 Active-Active、不拆服务。  
On the existing org skill catalog and single-region identity, make the private catalog recognizable, fail closed on remote pack hosts, and report multi-region as disabled. No billing, no Active-Active, no service split.

达到可打 **`v4.3.0`** 标签的功能与文档水位。  
Reach the feature and doc watermark for a manual **`v4.3.0`** tag.

做法 / Approach：A。不新开市场服务；收紧现有 catalog 拉取，并在现有探针上标明非多活。  
Approach A: no new marketplace service. Tighten the existing catalog fetch and mark non-Active-Active on the current probes.

## 3. 不包含范围（本版本 Out）

- 公网 Marketplace、计费、CDN、支付  
- 真正 Active-Active、跨区复制、全局流量调度  
- 新业务表、独立市场服务  
- SAML / 强制默认 OIDC  

No public marketplace, no billing, and no cross-region replication.
