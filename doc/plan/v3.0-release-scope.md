## 1. 发布目标

在 v2.5–v2.7 已有 Qdrant POC / Embedder / `prefer=vector` 之上，交付 **Chroma + Milvus 可选适配**，并将 Hybrid 向量路径 **升格为可选强检索面**；**保留 Qdrant**；默认仍可不依赖外部向量库。

达到可打 **`v3.0.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| 多后端契约 | `VectorStore` 统一面；`ASH_RAG_VECTOR_BACKEND=qdrant\|chroma\|milvus\|mock`（**DX43**） |
| Chroma 适配 | HTTP/SDK 兼容客户端；超时/取消；mock（**DX44**） |
| Milvus 适配 | 同上（**DX45**） |
| Hybrid 升格 | `prefer=vector` / `hybrid+vector` 行为硬化；失败回退 FTS/hybrid（**DX46**） |
| 证据 + 水位 | `rag-vector-smoke` 扩展；Scale/Knowledge 后端可用性（**DX47**） |
| 冻结 + 签字 | `v3.0-release-scope` 冻结；`make v3.0-signoff`（**DX48**） |

## 3. 不包含范围（本版本 Out）

- 公网 Skill Marketplace / 计费 / CDN  
- Active-Active  
- IdP 联邦 / Session 多端网关（→ **v3.2**）  
- Quest 委派面大改（→ **v3.1**）  
- 删除 Qdrant 或强制唯一云向量供应商  
- 向量库作为 **默认硬依赖**（无后端时 skip / 回退）  

## 4. 变更冻结规则（DX48 起生效）

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v3.0.0` tag** 前须完成本文件签字表 + `make v3.0-signoff` 绿  

## 5. 验收门禁（自动化 · 冻结后）

```bash
make scope-freeze-gate    # 含 v3.0
make v3.0-signoff         # Doctor ALL/M4 + rag-hybrid + rag-vector + sandbox + skill-pack + rag-lsp + remote-sandbox
make openapi-check
make rag-vector-smoke
```
