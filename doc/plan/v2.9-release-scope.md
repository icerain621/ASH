## 1. 发布目标

在 v2.8 LSP 切片之上，交付 **可选远程强隔离沙箱**（E2B-class / 兼容 API）作为 Landlock 的升级路径，并保留本机默认；**不**把公网 Marketplace、Active-Active、第二向量库做成默认依赖。

达到可打 **`v2.9.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Executor 契约 | 正式化 `sandbox/remote` 扩展点；配置/探测；默认仍本机 Landlock/process（**DX37**） |
| E2B-class 适配器 | 可选 HTTP/SDK 客户端（env 开启）；创建/超时/取消；**非默认**（**DX38**） |
| 策略接线 | isolated/danger 可声明 prefer remote；失败回退本机或拒绝（可配置）（**DX39**） |
| 证据 + Doctor | smoke / 可选 live；无 key → skip pass；清单与证据（**DX40**） |
| 控制台水位 | Scale/Observability 展示 remote 可用性（**DX41**） |
| 冻结 + 签字 | `v2.9-release-scope` 冻结；`make v2.9-signoff`（**DX42**） |

## 3. 不包含范围（Out）

- 远程沙箱作为 **默认** 或发布硬依赖 / 计费云强制  
- 公网 Skill Marketplace、评分、计费、CDN  
- Active-Active 多区域  
- Chroma / Milvus 主路径适配器  
- IdP 联邦 / 多端网关  
- 云 RDS / GitHub·ExecGo live 强制  

## 4. 变更冻结规则（DX42 起生效）

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v2.9.0` tag** 前须完成本文件签字表 + `make v2.9-signoff` 绿
