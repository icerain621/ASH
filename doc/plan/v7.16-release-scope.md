## 1. 发布目标 / Release goal

未批准 / 未知插件组件（含 `mem.*`）绑定生产时返回稳定业务码；生产查询 API 对未批准组件返回 HTTP 403；运行失败码与 `apicodes` 对齐。  
Unapproved or unknown plugin components (including `mem.*`) fail production bind with stable codes; the production lookup API returns HTTP 403 for unapproved components; run failure codes stay aligned with `apicodes`.
