## 1. 发布目标 / Release goal

Create 在写入 run 行之前校验场景内全部生产模板引用；未批准返回 403 / `AGENT_TEMPLATE_NOT_APPROVED`，未知返回 404 / `AGENT_TEMPLATE_UNKNOWN`，避免先建 run 再在步骤中失败。  
Validate all production template refs in the scenario before Create inserts a run row; unapproved → 403 / `AGENT_TEMPLATE_NOT_APPROVED`, unknown → 404 / `AGENT_TEMPLATE_UNKNOWN`, so runs are not created only to fail mid-step.
