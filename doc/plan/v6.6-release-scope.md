## 1. 发布目标

GitHub Webhook 成功入库后，把一条 `ci.webhook` 交给已有 Notifier。默认 `ASH_NOTIFIER=null` 丢弃且不失败；`log` 打到标准日志。重复投递不再通知。无 IM、无新表。  
After a successful GitHub webhook ingest, hand a `ci.webhook` event to the existing Notifier. Default `null` discards without failing the request; `log` prints it. Duplicates are not notified again. No IM and no new table.

达到可打 **`v6.6.0`** 标签的功能水位（冻结后）。  
Reach the watermark for a manual **`v6.6.0`** tag (after freeze).

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| 活路径 | 非重复入库后 `notify.FromEnv().Notify`（**VX61**） |
| 响应标记 | `notifier`（`null` 或 `log`） |
| 冻结 + 签字 | 本文件冻结；`make v6.6-signoff`（**VX62**） |

## 3. 不包含范围（本版本 Out）

- Hermes 全 IM、飞书/企微/Telegram  
- 通知失败回滚 CI 入库  
- 新业务表、公网计费、Cordis / YOLO  

Notifier failure does not roll back CI ingest.

## 4. 变更冻结规则（VX62 起生效）

- 冻结后仅接受 P0 缺陷、文档/门禁  
- HTTP 变更须 `make openapi-check`  
- 打 **`v6.6.0` tag** 前须签字 + `make v6.6-signoff` 绿  

## 5. 验收门禁（VX62）

门禁脚本在 VX62 落地。不自动打 tag。
