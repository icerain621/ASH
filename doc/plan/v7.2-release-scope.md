## 1. 发布目标 / Release goal

超预算时写出从原文抽出的可回放摘要，而不是占位句。技能前缀只含名称和触发说明。循环内扣减 token，用尽时先压缩再拒绝。Steer 与 follow-up 使用不同事件名。  
Over budget, write a replayable extractive summary instead of a placeholder sentence. Skill prefixes carry only the name and trigger text. The loop decrements tokens and compacts before refusing. Steer and follow-up use different event names.

## 2. 包含范围（P2 · In）
