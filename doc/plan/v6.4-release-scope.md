## 1. 发布目标

在已有 GitHub Webhook、Model Router、私有技能目录之上，交付 **Ingress 适配器缝（零 IM 矩阵）**、**Provider 目录可辨认标记**，以及 **组织 Skills Hub 姿态一句**。不引入 Hermes 全 IM、不公网市场、不计费。  
On existing GitHub Webhook, Model Router, and private skill catalog, ship an Ingress adapter seam (zero IM matrix), recognizable Provider catalog markers, and an org Skills Hub posture line. No Hermes full IM, no public marketplace, no billing.

达到可打 **`v6.4.0`** 标签的功能与文档水位（冻结后）。  
Reach the feature and doc watermark for a manual **`v6.4.0`** tag (after freeze).

做法 / Approach：A。只加适配器缝与响应标记；不新开 Gateway 服务、不接第二 IM 通道。  
Approach A: adapter seam + response markers only; no new Gateway service, no second IM channel.

## 3. 不包含范围（本版本 Out）

No Hermes IM matrix, no public marketplace, and no auto-tag.
