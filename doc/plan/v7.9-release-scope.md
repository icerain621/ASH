## 1. 发布目标 / Release goal

CLI 上 `ash doctor` 与 `ash review` 分清：诊断只跑运行套件；评审列出/决定队列、跑 Pass^k、列模板状态。模板候选与评审条目写入 G01 表（写穿），列表可读库。  
Split CLI so `ash doctor` stays runtime-only and `ash review` lists/decides the queue, runs Pass^k, and lists template status. Template candidates and review items write through to G01 tables; lists can read the store.
