## 归属边界

- 不写协议细节（→ `appendices/` / `api/`）  
- 不写操作步骤长文（→ `checklists/`）  
- 不存门禁输出（→ `evidence/`）  

真相源优先级：`PLAN` ≫ `TODO` ≫ CHANGELOG（事实）≫ archive（历史）。
