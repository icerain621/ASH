## 1. 发布目标

把 v6.3 已有的沙箱后端目录接到 Harness Profile 列表与 active 响应，控制台回显同一组 ID。不写入 profile spec，不开通新厂商。  
Project the existing sandbox backend catalog onto harness profile list and active responses, and show the same IDs in the console. The catalog is not stored on the profile spec and adds no vendor.

达到可打 **`v6.7.0`** 标签的功能水位。  
Reach the watermark for a manual **`v6.7.0`** tag.
