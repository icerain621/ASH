## 0. 为何是 v7 而不是 v6.8

v6.7 只回显 Harness 沙箱目录。本代要换的是装配方式：循环进 ASH、Workflow 变薄、记忆变成可引用组件、Doctor 与评审分开、观测成为主产品。这是新程序，不是 v6 的补丁。  
v6.7 only echoes sandbox backend IDs. v7 changes how agents, harnesses, and memory are assembled. It is a new program, not a v6.8 patch.

## 1. 产品意图

> **ASH v7 = 用同一颗粒度的组件拼 Agent 与记忆，用薄 Workflow 编排，用三个镜头看清运行，用评审而不是 Doctor 判断好坏。**

- 组件合同对齐 Pi 的 Loop / Harness / Tools / Context / Compaction / Skills，不移植 TUI，不把 `pi` 当子进程。  
  Component contracts follow Pi. No TUI port, no `pi` subprocess harness.
- 记忆组件（`mem.*`）与工具组件同一插件宿主、同一评审门。Agent Manifest 用 `memory: []` 引用。  
  Memory components share the plugin host and review gate. Agents reference them.
- 存储仍是 L0–L3。写入类组件只产候选。  
  The store stays L0–L3. Write-class components only create candidates.
- Doctor 只回答「ASH 能否运行」。评审回答「模板、Harness、记忆、产物够不够好」。  
  Doctor answers runtime health. Review answers quality.
- 观测是主导航能力：全局、Agent、记忆体三个镜头，评审台右侧嵌入同一镜头。  
  Observation is primary navigation: global, agent, and memory lenses. Review embeds the same lens.

## 3. 全部功能点 / Feature catalog

### P0 · 上下文与记忆引用

| ID | 功能点 |
|----|--------|
| A04 | Context Pack：Gather → Select → Structure → Compress；静态前缀在一次 run 内保持稳定 |
| B06 | ExecGo/ACP 变为 Runtime 插件；请求携带 Context Pack；不能绕过效果门 |
| D01 | `mem.retrieve`：按空间、层、敏感级检索；越权结果为空 |
| D05 | `mem.inject`：唯一进入 Context Pack 的记忆通道；模板未引用则不注入 |
| D08 | 记忆组件与 Agent 组件同一宿主、同一评审门 |
| I01 | 组件信号目录：事件类型登记后才能进镜头 |

### P1 · Agent 循环与内置模板

| ID | 功能点 |
|----|--------|
| A01 | Agent Loop：思考、工具、观察；停止原因含无工具、终稿、不可恢复、达上限、取消 |
| A02 | Harness Drive：重试、恢复、检查点、效果门、工具放置 |
| A03 | 工具合同：名称、描述、参数、风险、执行。内置 read/write/edit/bash 接到 toolbus |
| A09 | Manifest：`loop` `tools` `compaction` `sandbox` `skills` `hooks` `maxTurns` `memory` |
| A10 | Hooks 接到 Loop 的每次工具调用 |
| B01 | 五个内置模板版本化：`tpl.react` `tpl.plan-solve` `tpl.reviewer` `tpl.memory-curator` `tpl.research` |
| D07 | `mem.feedback`：hit_used、用对、错误更新 |

内置模板的默认记忆引用：

| 模板 | `memory` |
|------|----------|
| `tpl.react` | `mem.retrieve` + `mem.inject` |
| `tpl.plan-solve` | 规划轮仅 retrieve；执行轮再 inject |
| `tpl.reviewer` | 不引用写入类记忆组件 |
| `tpl.memory-curator` | `mem.retrieve` + `mem.consolidate` + `mem.forget` |
| `tpl.research` | `mem.retrieve` + `mem.inject` + `mem.feedback` |

### P2 · 压缩与模型端口

### P3 · 薄 Workflow 与 RAG

| ID | 功能点 |
|----|--------|
| C01 | 场景步骤只留 `agent` / `human` / `review` |
| C02 | 一个主版本内把旧 `llm` / `tool_chain` / `verify` 映射到模板，并打弃用事件 |
| C03 | `feature_delivery` 改为 `plan-solve → react → reviewer → human` |
| C04 | 无场景对话只跑 `tpl.react` |
| C05 | `executeSteps` 只做准备 Context、调用模板、记事件 |

| E02 | 保留 Hybrid RRF / 符号索引 |
| E04 | 引用门禁留在 Agent/评审，不放进 Doctor |

### P4 · 评审、Doctor、记忆巩固

| ID | 功能点 |
|----|--------|
| D02 | `mem.consolidate`：合并去重只进评审队列 |
| D03 | `mem.forget`：过期、低置信、长期未使用进入遗忘提案 |
| D04 | `mem.propose`：必须带证据；轨迹原文不能升格为记忆 |
| D06 | 保留 L0–L3、知识投影经 `mem.knowledge` 只读引用 |
| F01 | Doctor 只保留配置、数据库、schema、路由、沙箱后端、Provider 配置、worker 存活 |
| F02 | 交付质量、Agent 成败、产物质量、记忆对错迁出 Doctor |
| F03 | 评审对象：模板、Harness、记忆、产物、运行样本 |
| F04 | Pass^k 在评审中抽样，不随每次启动跑 |
| F05 | 记忆三计数：记得、用对、错误更新 |
| F06 | 评分与 Improve 归评审；verify 失败可有上限地再规划 |

| ID | 功能点 |

| G05 | 四产品对照里 P08、P23 改指向 v7 设计 |
| H01 | Loop、GSSC、压缩、敏感过滤、模板加载的单测 |

### P6 · 三镜头观测（核心产品）

| ID | 功能点 |
|----|--------|
| I02 | 全局镜头：在跑、失败簇、模板用量、门禁拒绝、预算、评审深度、Doctor 芯片 |
| I03 | Agent 瀑布：pack、turn、tool、compaction、停止原因、steer |
| I04 | 记忆谱系：候选 → 评审 → 批准 → 注入 → hit_used → 巩固/遗忘提案；敏感正文默认打码 |
| I05 | 观测升为主导航；深链 `/observe?lens=agent&run=` 与 `lens=memory&id=` |
| I06 | 评审台右侧嵌入对应镜头；决定写回评审 |
| I07 | Agent 对话壳与记忆详情复用同一镜头组件 |
| I08 | OTel / Prometheus 仍从事件脊柱导出；导出失败不影响站内镜头 |
| I09 | 三处深链互相跳转且 id 一致 |
| H06 | 上述深链的契约测试 |

记忆组件一览：`mem.retrieve` `mem.inject` `mem.propose` `mem.consolidate` `mem.forget` `mem.feedback` `mem.knowledge`。

## 4. 明确不做 / Out of scope

- 不改写已冻结的 v6.0–v6.7 release-scope 正文，不开 v6.8 承载本程序。  
  Do not rewrite frozen v6 scopes, and do not host this program as v6.8.
- 不移植 Pi TUI、无沙箱信任模型，不把 ASH 改成 Node。  
  Do not port Pi’s TUI or trust-without-sandbox model, and do not rewrite ASH as Node.
- 本程序不做 Agentic RL、A2A、公网技能市场、Hermes 全通道、Cordis、YOLO。  
  No Agentic RL, A2A, public skill market, full Hermes IM, Cordis, or YOLO.
- 不用外置记忆产品替换 L0–L3。不为三个镜头各建一套库。  
  Do not replace L0–L3. Do not build a store per lens.
- Doctor 不再扩大成质量平台。  
  Do not grow Doctor back into a quality platform.
