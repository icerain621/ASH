## 1. 发布目标 / Release goal

控制台拆开 Agent 模板、Harness/插件组件、评审队列与运行诊断；列表带批准状态；未批准模板在控制台标明不可绑定运行。  
Split the console into agent templates, harness/plugin components, review queue, and runtime diagnostics. Lists show approval status. Unapproved templates are marked non-bindable in the console.
