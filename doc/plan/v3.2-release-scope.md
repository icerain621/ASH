## 1. 发布目标

交付 **IdP 联邦薄切片**（OIDC → 现有 ASH JWT）与 **多端 Session 网关 POC**；不改默认 Auth 模式；Doctor 保持 57/10。

达到可打 **`v3.2.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| OIDC 薄切片 | 登录/回调 → ASH JWT（**DX55**） |
| 联邦用户 | `users.oidc_*` 绑定 / JIT（**DX56**） |
| Session 网关 POC | 多端/设备 scoped token（**DX57**） |
| Session 硬化 | refresh + scope 强制（**DX58**） |
| 控制台 + smoke | `/ui/login` + Sessions + `oidc-console-smoke`（**DX59**） |
| 冻结 + 签字 | `v3.2-release-scope`；`make v3.2-signoff`（**DX60**） |

## 3. 不包含范围（本版本 Out）

- 公网 Marketplace / 计费 / CDN / Active-Active  
- SAML / 多 IdP 同时启用（可后续）  
- 强制默认 OIDC（仍可选；`ASH_AUTH_MODE` 不变）  
- 删除本地密码登录  

## 4. 变更冻结规则（DX60 起生效）

- 冻结后仅接受 P0 缺陷、文档/门禁、Out 项环境证据  
- 新表须 SQL rev + RLS + Doctor（E5 例外须在 scope 标明）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v3.2.0` tag** 前须签字表 + `make v3.2-signoff` 绿  

## 5. 验收门禁

```bash
make scope-freeze-gate    # 含 v3.2
make v3.2-signoff
make openapi-check
```
