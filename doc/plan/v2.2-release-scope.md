## 1. 发布目标

在 v2.1 ACP 桥接之上交付 **持续职责（Waker）** 运维委派能力（队列扫描、安全 cancel 闸门、签字门禁），达到可打 **`v2.2.0`** 标签的功能与文档水位（云 live / Landlock 仍为环境或后续版本项）。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Waker 雏形 | `GET/POST /waker/queue|sweep` + `ASH_WAKER_RUN_TTL` / `ASH_WAKER_INTERVAL`（report/flag）（**DX6**） |
| Waker cancel | `ASH_WAKER_ALLOW_CANCEL` + `confirm=CANCEL_STALE_RUNS` + 审计；后台永不 cancel（**DX7**） |
| Doctor / 签字 | `v2.2-release-scope` 冻结；`make v2.2-signoff`（含 `waker-smoke`）（**DX8**） |

## 3. 不包含范围（本版本 Out）

- Landlock / E2B 级 OS 沙箱
- 自动 cancel 生产默认策略（须显式 env + confirm）
- 云 RDS / 真实 GitHub·ExecGo live 强制
- 向量库主路径、Hybrid 符号索引、Skill Marketplace

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）
- 破坏性 API 须 OpenAPI + `make openapi-check`
- 打 **`v2.2.0` tag** 前须完成本文件签字表 + `make v2.2-signoff` 绿
