## 1. 发布目标

在已有 PluginRegistry gRPC 骨架上，交付 **生产可开、失败即关** 的插件监听，以及 **进程内** RAG Indexer 契约（proto + 可选本机 gRPC，委托现有索引/检索）。不拆 Session 微服务，不部署独立 Indexer 进程。  
On the existing PluginRegistry gRPC skeleton, ship a production listen path that fails closed, plus an in-process RAG Indexer contract (proto and an optional loopback gRPC that calls the current index/query). No Session split and no separate Indexer process.

达到可打 **`v4.2.0`** 标签的功能与文档水位。  
Reach the feature and doc watermark for a manual **`v4.2.0`** tag.

做法 / Approach：A。生产路径收紧现有注册服务；Indexer 只加契约与进程内适配，不新开部署单元。  
Approach A: tighten the existing registry for production; add the Indexer contract and an in-process adapter only.

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| 生产监听 | 非 dev 且设置了 `ASH_PLUGIN_GRPC_ADDR` 时，缺签名密钥或未强制签名则拒绝启动（**DX73**） |
| 注册门禁 | gRPC `Register` 在强制签名下拒绝无签名插件；现有 HTTP 注册行为不变（**DX74**） |
| Indexer 契约 | `proto/ash/v1/rag_indexer.proto`（`IndexRepo` / `Query`）+ `make proto-check`（**DX75**） |
| 进程内适配 | `ASH_RAG_INDEXER_GRPC_ADDR` 为空则不监听；设置后本机委托现有 RAG，无新表（**DX76**） |
| 姿态可见 | `GET /api/v1/plugins/abi` 增加监听是否开启（插件 / Indexer），不新增页面（**DX77**） |
| 冻结 + 签字 | 本文件冻结；`make v4.2-signoff`（**DX78**） |

## 3. 不包含范围（本版本 Out）

- 拆 Session / 编排微服务  
- 独立 Indexer 进程、多副本、跨机检索  
- `EventStream` / `ObservabilityExporter` gRPC（附录 H 仍为后续）  
- 默认监听 `0.0.0.0` 或在非 dev 下自动开端口  
- Marketplace / 多区域 / 公网计费（→ **v4.3**）  
- 真计费、SAML、新业务表  

Do not split Session, do not run a remote Indexer, and do not add EventStream or ObservabilityExporter gRPC in this version.
