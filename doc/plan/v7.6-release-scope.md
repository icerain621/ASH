## 1. 发布目标 / Release goal

观测升为主导航：全局 / Agent / 记忆三镜头共用事件脊柱；深链 id 一致；评审台与对话壳可嵌入同一镜头。  
Observation becomes a primary nav: global / agent / memory lenses share the event spine; deep-link ids stay consistent; review desk and chat shell can embed the same lens.

## 2. 包含范围（P6 · In）

| ID | 交付 |
|----|------|
| I02 | 全局镜头：在跑、失败簇、模板用量、门禁拒绝、预算、评审深度、Doctor 芯片（只读聚合） |
| I03 | Agent 瀑布：pack、turn、tool、compaction、停止原因、steer（复用现有 waterfall API） |
| I04 | 记忆谱系：候选 → 评审 → 批准 → 注入 → hit_used → 巩固/遗忘；敏感正文默认打码 |
| I05 | 主导航「观测」；深链 `/ui/observe?lens=agent&run=` 与 `lens=memory&id=` |
| I06 | 评审台右侧嵌入对应镜头（不新建第二套瀑布） |
| I07 | Agent 对话壳与记忆详情复用同一镜头深链 |
| I08 | OTel / Prometheus 仍从事件脊柱导出；导出失败不影响站内镜头 |
| I09 | 三处深链互相跳转且 id 一致 |
| H06 | 上述深链的契约测试（前端 + API） |
