## 1. 发布目标

在 v2.4 Waker 职责平面之上，交付 **探针自动 seed + ctags 符号索引 + 向量检索 POC + Landlock 沙箱 POC**，达到可打 **`v2.5.0`** 标签的功能与文档水位（真实 embedding 硬依赖、E2B、Skill Marketplace 仍为 Out）。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Waker probe seed | Status/Background 自动 seed `doctor_subset` / `kpi_drift`（默认 disabled）；`POST /waker/duties/{id}/enable`；Observability 切换；`ASH_WAKER_ENABLE_PROBES`（**DX15**） |
| ctags 符号索引 | `SymbolIndexer` 可插拔；ctags 子进程 + regex 回退；`rag_symbols.source`（SQL **30**）；`symbolSource`（**DX16**） |
| Vector POC | Qdrant HTTP + HashEmbedder；`rag_vector_refs`（SQL **31** / RLS **51**）；Query 第 4 RRF lane；`make rag-vector-smoke`（**DX17**） |
| Landlock 沙箱 | Linux Landlock executor；`ASH_SANDBOX_LANDLOCK`；Doctor **M4-SBX-04**（**DX18**） |
| 冻结 + 签字 | `v2.5-release-scope` 冻结；`make v2.5-signoff`（含 waker / rag-hybrid / rag-vector / sandbox）（**DX19**） |

## 3. 不包含范围（本版本 Out）

- Skill Marketplace、计费、多区域
- 生产默认自动 cancel（须显式 `ASH_WAKER_ALLOW_CANCEL` + confirm + `dryRun=false`；后台永不 cancel）
- 真实 embedding API 作为硬依赖（HashEmbedder POC 足够）
- E2B / 完整 seccomp 配置
- 云 RDS / 真实 GitHub·ExecGo live 强制
- LSP / tree-sitter（ctags only）
- Chroma / Milvus 适配器

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）
- 破坏性 API 须 OpenAPI + `make openapi-check`
- 打 **`v2.5.0` tag** 前须完成本文件签字表 + `make v2.5-signoff` 绿
