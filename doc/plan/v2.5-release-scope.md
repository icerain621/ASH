# ASH v2.5 发布范围（草案）

> 状态：**草案**（2026-09-03）  
> 归属：[`plan/`](README.md)  
> 版本锚点：Doctor ALL **55/55** · SQL rev **31**（计划）· RLS **52**（计划）· Sprint **DX15–DX18**  
> 前置：v2.4 已冻结（DX12–DX14；tag `v2.4.0` 仍待人工）  
> 设计：[`docs/superpowers/specs/2026-09-03-v25-dx15-dx18-design.md`](../superpowers/specs/2026-09-03-v25-dx15-dx18-design.md)

## 1. 发布目标

在 v2.4 Waker 职责平面之上，交付 **探针自动 seed + ctags 符号索引 + 向量检索 POC + Landlock 沙箱 POC**，达到可打 **`v2.5.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Waker probe seed | 自动 seed `doctor_subset` / `kpi_drift`（默认 disabled）；enable API + 控制台切换（**DX15**） |
| ctags 符号索引 | `SymbolIndexer` 可插拔；ctags 子进程 + regex 回退；`rag_symbols.source`（**DX16**） |
| Vector POC | Qdrant HTTP + stub embedder；`rag_vector_refs`；Query 第 4 RRF lane（**DX17**） |
| Landlock 沙箱 | Linux Landlock executor；`ASH_SANDBOX_LANDLOCK`；Doctor M4-SBX-04（**DX18**） |
| 冻结 + 签字 | `v2.5-release-scope` 冻结；`make v2.5-signoff`（**DX19**） |

## 3. 不包含范围（本版本 Out）

- Skill Marketplace、计费、多区域
- 生产默认自动 cancel
- 真实 embedding API 作为硬依赖
- E2B / 完整 seccomp 配置
- 云 RDS / GitHub·ExecGo live 强制
- LSP / tree-sitter（ctags only）

## 4. 验收门禁（自动化）

```bash
make scope-freeze-gate    # 含 v2.5 scope 结构（DX19）

```
