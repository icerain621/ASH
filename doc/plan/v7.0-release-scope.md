## 1. 发布目标 / Release goal

运行在调用外置执行器之前打出 `context.packed`，请求携带 Context Pack。记忆只经 `mem.inject` 进入该包；越权检索为空；未批准的记忆组件不能绑定生产模板。  
Emit `context.packed` before an external executor runs, and put the Context Pack on the request. Memory enters that pack only through `mem.inject`. Over-clearance retrieval is empty. An unapproved memory component cannot bind a production template.

## 2. 包含范围（P0 · In）

| ID | 交付 |
|----|------|
| A04 | `internal/contextpack`：Gather → Select → Structure → Compress；同输入前缀字节稳定 |
| B06 | `agentexec.Request.ContextPack`；ExecGo / ACP 缺少该包时拒绝执行 |
| D01 | `mem.retrieve` 按敏感级过滤；调用方许可低于记录时结果为空 |
| D05 | 未声明 `mem.inject` 时包内无记忆引用；`mem.inject` 无 `mem.retrieve` 时绑定失败 |
| D08 | `internal/plugins` 内置宿主；候选组件不能绑定生产引用 |
| I01 | `internal/observability/lenses` 信号目录；未登记事件不进入产品镜头 |

尚无模板 ID 的旧场景步骤，按内置 `tpl.react` 的记忆引用（`mem.retrieve` + `mem.inject`）打包，以免现有交付丢掉已批准记忆。  
Legacy steps without a template id pack with the `tpl.react` memory refs so approved memory still reaches delivery.

P1 through P6 stay out: the in-process loop, runtime template switching, real compaction, thin workflow, the Doctor split, and the three-lens console.
