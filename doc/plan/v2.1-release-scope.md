## 1. 发布目标

在 v2.0 双核心底座上交付 **ACP 控制面桥接（骨架→Session 互通→任务契约→Doctor 探针）**，达到可打 **`v2.1.0`** 标签的功能与文档水位（真实 ACP 生产服务与云 live 仍可为环境门禁项）。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| ACP Provider | `ACPExecutor` + `ProbeACP` + `/providers/agent.acp` + fallback（**DW**） |
| ACP ↔ Session | `providerKind` + `EnsureForRun` + `session.linked` + AgentTask `sess_*`（**DX3**） |
| ACP 契约 | `ash.acp.task.v1` + `cmd/acp-mock` + `make acp-smoke` + turn 转发（**DX4**） |
| Doctor / 签字 | M4-ACP-01/02；ALL **55**；`make v2.1-signoff`（**DX5**） |

## 3. 不包含范围（本版本 Out）

- 云 RDS 生产切流签字（H-01～H-03）
- ExecGo/GitHub **真实 live** 强制（脚本已有，需密钥）
- Landlock / E2B 级 OS 沙箱
- 生产 ACP 控制面完整协议实现（mock + HTTP 契约即可）
- 向量库主路径、Skill Marketplace、外部 IdP

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）
- 破坏性 API 须 OpenAPI + `make openapi-check`
- 打 **`v2.1.0` tag** 前须完成本文件签字表 + `make v2.1-signoff` 绿
