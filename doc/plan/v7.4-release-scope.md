## 1. 发布目标 / Release goal

写入类记忆组件只产评审提案，不改已批准正文。Doctor 增加纯启动诊断套件 `BOOT`。评审包能排队、决定、Pass^k 抽样与记忆三计数。  
Write-class memory components only create review proposals; they do not rewrite approved bodies. Doctor gains a boot-only `BOOT` suite. The review package can queue, decide, sample Pass^k, and tally the three memory evaluation counters.

## 2. 包含范围（P4 · In）

| ID | 交付 |
|----|------|
| D02 | `mem.consolidate`：合并提案进队列；无评审不改 approved 正文 |
| D03 | `mem.forget`：遗忘提案（过期 / 低置信 / 长期未用可触发）；可驳回 |
| D04 | `mem.propose`：必须有证据；拒绝轨迹原文类证据 kind |
| D06 | `mem.knowledge` 只读引用知识投影；不另建库 |
| F01 | Doctor 套件 `BOOT`：配置/库/OpenAPI/readyz/插件 ABI/产物存储等启动探针 |
| F02 | 质量类用例 ID 登记在 `internal/review`（过渡期仍可在 TR 全量里跑，本波不砍 ALL 计数） |
| F03 | `internal/review`：对象种类 template / harness / memory / artifact / run_sample；提交与决定 |
| F04 | `internal/review/passk`：可配置 k 次抽样；不挂到每次 Doctor 启动 |
| F05 | 记忆三计数：`remembered`（hit_used）、`used_correctly`、`wrong_update` |
