## 1. 发布目标

在 v2.6 之上，把四条能力轨 + 硬化项收成 **可验证 MVP**（不做满公网市场 / Active-Active / E2B 默认 / 完整 LSP）：

1. **向量硬化 + 真实 Embedding**（C + B3）  
2. **沙箱证据面**（C + B2 的可交付切片；E2B 仍 Out）  
3. **组织级 Skill 目录 + UI**（B4 的可交付切片；公网市场 Out）  
4. **薄 LSP 符号**（B1/B8 必做切片；完整语言服务 Out）  

达到可打 **`v2.7.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Vector harden | `prefer=vector` + merge 测；Qdrant create-if-missing；Profile 向量诚实性（**DX25** · C） |
| Real Embedder | OpenAI-compat HTTP Embedder；Hash 回退；可选 live smoke（**DX26**） |
| Sandbox evidence | Linux Landlock+seccomp e2e 清单/CI 证据包；Executor 缝保留（**DX27**）；**不接 E2B 云 API** |
| Org skill catalog | 签名 catalog 列表（HTTPS/本地 JSON）+ verify→install；Automation UI 打磨（**DX28**） |
| Thin LSP（必做 · B8） | `gopls`/`tsserver` 一次性 `documentSymbol` → `SymbolIndexer`；`source=lsp`；无常驻守护（**DX29**） |
| 冻结 + 签字 | `v2.7-release-scope` 冻结；`make v2.7-signoff`（**DX30**） |

## 3. 不包含范围（本版本 Out）

- **完整 LSP 客户端**（hover / defs·refs / 诊断流 / 多语言守护生命周期）— 可进 v2.8  
- **E2B / 远程 microVM 作为默认或硬依赖**（可保留接口注释；不计费云调用）  
- 公网 Skill Marketplace、评分、计费、CDN  
- Active-Active 多区域 / 数据驻留产品化（保留 `ASH_REGION` 单区域）  
- Chroma / Milvus 适配器；Embedding 作为发布硬依赖  
- 云 RDS / GitHub·ExecGo live 强制  

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v2.7.0` tag** 前须完成本文件签字表 + `make v2.7-signoff` 绿
