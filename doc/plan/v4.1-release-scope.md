## 1. 发布目标

在 v4.0 Auth 之上，交付 **企业 Agentic 可配置与可见**：org/space 配额占位（并发 Run · token 代理预算）、审计薄报表、spawn 策略/预算投影；不真计费、不拆服务。  
Deliver configurable, visible enterprise Agentic on v4.0: quota placeholders, a thin audit report, and spawn policy/budget projection. No real billing and no service split.

达到可打 **`v4.1.0`** 标签的功能与文档水位。  
Reach the feature and doc watermark for a manual **`v4.1.0`** tag.

## 2. 包含范围（P0 · In）

- 收紧配额时强制杀掉存量 Run  
- SAML / 强制默认 OIDC  
- Plugin gRPC / 外置 Indexer（→ **v4.2**）  
- Marketplace / 多区域（→ **v4.3**）  
- 公网计费 / Active-Active
