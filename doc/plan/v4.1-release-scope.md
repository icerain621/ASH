## 1. 发布目标 / Release goal

在 v4.0 Auth 之上交付企业 Agentic **可配置与可见**：配额占位、审计薄报表、spawn 策略/预算投影；不真计费、不拆服务。  
Deliver **configurable, visible** enterprise Agentic: quota placeholders, thin audit report, spawn policy/budget projection; no real billing; no service split.

可打标签 / Tag-ready: **`v4.1.0`**.

## 2. 包含范围 / In（P0）

| 域 / Domain | 交付 / Deliverable |
|----|------------------|
| 配额门禁 / Quota gate | `bodyJson.quotas`；Create/Spawn fail-closed（**DX67**） |
| 配额投影 / Quota projection | `GET …/quotas` + console（**DX68**） |
| 审计报表 / Audit report | `GET …/audit-report`（**DX69**） |
| 报表 UI / Report UI | Compliance/Space card（**DX70**） |

| 冻结签字 / Freeze signoff | 本文件 + `make v4.1-signoff`（**DX72**） |

## 3. 不包含 / Out

- 真计费 / Real billing  
- 跨 org 汇总 / Cross-org rollups  
- 强杀存量 Run / Force-kill running runs  
- SAML / 强制默认 OIDC  
- Plugin gRPC / Indexer → **v4.2**  
- Marketplace / 多区域 → **v4.3**  
- Active-Active
