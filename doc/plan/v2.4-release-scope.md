> 状态：**已冻结**（2026-09-02，产品占位确认；真人签字见 [`../checklists/v2.4-signoff.md`](../checklists/v2.4-signoff.md)）

> 关联：[`v2.3-release-scope.md`](v2.3-release-scope.md) · [`sprint-dx12-waker-duties.md`](sprint-dx12-waker-duties.md) · [`sprint-dx13-waker-probes.md`](sprint-dx13-waker-probes.md)

## 1. 发布目标

在 v2.2 Waker 运维底座与 DX9 Hybrid 之上，将 Waker 升级为 **可调度、可审计、可观测的持续职责平面**（duty ledger + probes + 控制台），达到可打 **`v2.4.0`** 标签的功能与文档水位（Landlock、默认自动 cancel、向量库仍为 Out）。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Duty ledger | 表 `waker_duties` / `waker_duty_runs`（SQL **29** / RLS **50**）；默认 ensure `stale_run`；ticker 读账本，只 report/flag（**DX12**） |
| Status / duties API | `GET /waker/status` · `GET /waker/duties` · `POST /waker/duties/{id}/run`；既有 queue/sweep 兼容；cancel 闸门不变（**DX12**） |
| Multi-duty probes | `doctor_subset` + `kpi_drift` → 统一 queue item + duty_run 行（**DX13** · 方案 A 不自动 seed） |
| Console + 签字 | Observability/Scale Waker 面板；`v2.4-release-scope` 冻结；`make v2.4-signoff`（含 `waker-smoke`）（**DX14**） |

## 3. 不包含范围（本版本 Out）

- Landlock / E2B 级 OS 沙箱
- 生产默认自动 cancel（须显式 `ASH_WAKER_ALLOW_CANCEL` + confirm + `dryRun=false`；后台永不 cancel）
- 向量库主路径（Chroma/Qdrant 等）
- 云 RDS / 真实 GitHub·ExecGo live 强制
- Skill Marketplace、微服务拆分 Waker
- 变更 DX9 Hybrid In-scope API（Scale/Obs 展示钩子除外）

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）
- 破坏性 API 须 OpenAPI + `make openapi-check`
- 打 **`v2.4.0` tag** 前须完成本文件签字表 + `make v2.4-signoff` 绿
