## 1. 发布目标 / Release goal

场景步骤只绑定 Agent 模板与人闸；旧 `llm` / `tool_chain` / `verify` 仍能启动并打出弃用事件。`feature_delivery` 改为模板链。无场景对话走 `tpl.react`。`rag.query` 可在研究模板内多轮调用。  
Scenario steps only bind agent templates and human gates. Legacy `llm` / `tool_chain` / `verify` still start and emit deprecation events. `feature_delivery` becomes a template chain. Chat without a scenario runs `tpl.react`. `rag.query` can be called across turns inside the research template.

## 2. 包含范围（P3 · In）

| ID | 交付 |
|----|------|
| C01 | 步骤种类主路径：`agent`（`templateId`）· `human` · `review`；schema / 校验接受 `review` 与 `agent.templateId` |
| C02 | 旧 `llm`→`tpl.plan-solve`；`tool_chain` / `verify` 打弃用事件仍走原路径（本主版本兼容门禁） |
| C03 | `feature_delivery`：`tpl.plan-solve` → `tpl.react` → `tpl.reviewer` |
| C04 | 无场景会话 PromptTurn 记录并走 `tpl.react`（一步路径） |
| C05 | 带 `templateId` 的步骤：准备 Context Pack → 调 Agent Loop → 记事件；不再走假 `llm` 路由 |
| E01 | `rag.query` 接到 `internal/rag` Query，可多轮调用 |
| E02 | 保留 Hybrid RRF / 符号索引（本波不改索引实现） |
| E04 | 引用门禁仍在 runs / Agent 步骤；不把业务引用质量断言迁进新 Doctor 用例 |

`kind: human` 校验与执行路径保留。程序表里的「末步 human」等 Doctor 探针能 Approve+Resume 后再并入 YAML，避免打断 TR0 成品契约。  
`kind: human` validation and execution stay. The catalog’s final human gate waits until Doctor probes can Approve+Resume, so TR0 finish contracts stay intact.

空间配额 `tokenBudgetProxyUsed`：模板循环若设置了 `TokenBudget` 则在该步扣减；未设置时仍为投影 0。  
`tokenBudgetProxyUsed` decrements when a template loop sets `TokenBudget`; otherwise the projection stays 0.
