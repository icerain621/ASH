## 1. 发布目标

在 v3.2 OIDC + Session 网关 POC 之上，交付 **生产向 Auth 硬化**：RS256 id_token、refresh 债收口、吊销硬化、可选控制台强制登录、device mint UI 薄切片；不强制默认 OIDC。

达到可打 **`v4.0.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| OIDC RS256 | JWKS 校验（**DX61** ✅） |
| Refresh 收口 | 独立 `typ=refresh` JWT + 双 token 轮换（Option B · **DX62** ✅） |
| 吊销硬化 | registry 当前/prev jti + grace（**DX63** ✅） |
| 控制台门闸 | 可选强制登录（`ASH_CONSOLE_AUTH_REQUIRED`；默认 off）（**DX64** ✅） |
| Device UI + smoke | Sessions 面板 mint + `make device-session-smoke`（**DX65** ✅） |
| 冻结 + 签字 | `v4.0-release-scope`；`make v4.0-signoff`（**DX66** ✅） |

## 3. 不包含范围（本版本 Out）

- SAML / 多 IdP 同时启用  
- 强制默认 OIDC（`ASH_AUTH_MODE` 默认不变）  
- 企业配额/审计报表（→ **v4.1**）  
- Plugin gRPC / 外置 Indexer（→ **v4.2**）  
- Marketplace / 多区域（→ **v4.3**）  
- 公网计费 / Active-Active  

## 4. 变更冻结规则（DX66 起生效）

- 冻结后仅接受 P0 缺陷、文档/门禁、Out 项环境证据  
- 新表须 SQL rev + RLS + Doctor（F4 例外须在本文件标明）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v4.0.0` tag** 前须签字表 + `make v4.0-signoff` 绿
