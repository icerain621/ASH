## 1. 发布目标

在 v2 DJ/DK 已有 Goal→Plan→Run 与 Quest 看板/Diff 之上，交付 **Quest 工作台委派面统一与硬化**：Goal/Plan UX、审查闭环、多入口一致性、看板 live；**尽量无新表**；Doctor 保持 57/10。

达到可打 **`v3.1.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| Quest Goal/Plan UX | Quest 页内联 compose + approve（**DX49**） |
| Diff 审查闭环 | 文件/全量拒绝 → 继续（**DX50**） |
| 工作台硬化 | waiting_approval 操作 + 产物面板（**DX51**） |
| 多入口委派 | webhook/session 等统一走 Plan（**DX52**） |
| 可见性 | 看板 live / `plan.*` SSE（**DX53**） |
| 冻结 + 签字 | `v3.1-release-scope`；`make v3.1-signoff`（**DX54**） |

## 3. 不包含范围（本版本 Out）

- IdP 联邦 / Session 多端网关（→ **v3.2**）  
- 公网 Marketplace / Active-Active  
- 向量后端大改（已在 v3.0）  
- 删除 Runs `quest-pane`（可并存）  

## 4. 变更冻结规则（DX54 起生效）

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v3.1.0` tag** 前须完成本文件签字表 + `make v3.1-signoff` 绿
