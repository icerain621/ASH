## 1. 发布目标

在 v2.7 薄 LSP（一次性 `documentSymbol`）之上，交付 **可产品化的 LSP 语言服务切片**（Go + TS/JS），并把结果接到 RAG / 控制台；**不**把 E2B / 公网市场 / Active-Active / 第二向量库做成默认依赖。

达到可打 **`v2.8.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · In）

| 域 | 交付物（Sprint） |
|----|------------------|
| LSP session | 工作区级短生命周期 LSP 会话（复用进程、超时回收）；非 IDE 守护（**DX31**） |
| Hover / Definition | `textDocument/hover` + `definition`；RAG/内部查询面（**DX32**） |
| References + 索引 | `references`（有界）+ Hybrid/Knowledge 接线；fallback → treesitter/regex（**DX33**） |
| 控制台水位 | Observability/Knowledge LSP 状态与样本查询（**DX34**） |
| 硬化 + smoke | 超时/打开文档上限、缺二进制降级、`rag-lsp-smoke`、证据清单（**DX35**） |
| 冻结 + 签字 | `v2.8-release-scope` 冻结；`make v2.8-signoff`（**DX36**） |

## 3. 不包含范围（Out）

- E2B / 远程 microVM 作为默认或硬依赖（含并行 E2B 接口 POC）  
- 公网 Skill Marketplace、评分、计费、CDN  
- Active-Active 多区域 / 数据驻留产品化  
- Chroma / Milvus 适配器；Embedding 作为发布硬依赖  
- 独立公开产品面 `/lsp/*`（暴露面限 RAG/内部 + 控制台）  
- 多语言全覆盖 IDE（仅 Go + TS/JS）  
- 云 RDS / GitHub·ExecGo live 强制  
- 新表 DDL（本版无新表）

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v2.8.0` tag** 前须完成本文件签字表 + `make v2.8-signoff` 绿  

## 5. 验收门禁（自动化 · 冻结后）

make scope-freeze-gate    # 含 v2.8
make v2.8-signoff         # Doctor ALL/M4 + rag-hybrid + rag-vector + sandbox + skill-pack + rag-lsp
