## 1. 发布目标 / Release goal

用有上限的工具循环跑内置模板。危险工具未经批准不执行。模板加载时拒绝非法记忆组合。`mem.feedback` 写下三层评估事件。  
Run built-in templates on a bounded tool loop. A danger tool does not run without approval. Illegal memory combinations fail at load. `mem.feedback` writes the three evaluation events.

## 2. 包含范围（P1 · In）

| ID | 交付 |
|----|------|
| A01 | `internal/agentloop`：停止原因为无工具、终稿、不可恢复、达上限、取消；`maxTurns < 1` 拒绝启动 |
| A02 | `internal/harness/drive`：重试、检查点、危险工具效果门 |
| A03 | 工具合同 `read` / `write` / `edit` / `bash`，接到 toolbus；路径不得逃出仓库根 |
| A09 | `internal/agenttpl` Manifest：`memory` 非法组合在加载时失败 |
| A10 | 循环内每次工具调用走现有 PreToolUse / PostToolUse |
| B01 | 五个内置模板版本 `1.0.0`，`GET /api/v1/agent-templates` 列出配方 |
| D07 | `mem.feedback` 写入 hit_used、用对、错误更新 |

模板版本先放在进程内目录。模板表与 RLS 属于后续 G01，不在本范围。  
Template versions live in the in-process catalog. Template tables and RLS belong to later G01.
