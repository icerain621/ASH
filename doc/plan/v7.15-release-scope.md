## 1. 发布目标 / Release goal

未批准或未知模板绑定失败时返回稳定业务码；生产查询 API 对未批准模板返回 HTTP 403；运行失败码与 `apicodes` 对齐。  
Unapproved or unknown template binding fails with stable business codes; the production lookup API returns HTTP 403 for unapproved templates; run failure codes stay aligned with `apicodes`.
