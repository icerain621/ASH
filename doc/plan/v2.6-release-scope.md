## 1. 发布目标

在 v2.5（ctags / Vector POC / Landlock POC / Waker probe seed）之上，交付三条能力轨的 **可验证 MVP**：

1. **符号索引增强** — tree-sitter 后端（可插拔；保留 ctags/regex）  
2. **沙箱硬化** — Landlock 默认策略收紧 + 最小 seccomp（Linux）；Docker/process 回退不变  
3. **Skills 私有分发** — 签名 skill pack 安装进本地目录（Marketplace 形态，非公网市场）+ **单区域就绪**（region 标签 / HA 文档，非 Active-Active）

达到可打 **`v2.6.0`** 标签的功能与文档水位。

## 2. 包含范围（P0 · 本版本 In）

| 域 | 交付物（Sprint） |
|----|------------------|
| tree-sitter 符号 | `TreeSitterIndexer` 实现 `SymbolIndexer`；`source=treesitter`；默认优先；`make rag-hybrid-smoke` 扩展（**DX20**） |
| 沙箱硬化 | Linux：isolated 在 Landlock Available 时默认走 landlock（可 `ASH_SANDBOX_LANDLOCK=0` 关）；最小 seccomp；Doctor **M4-SBX-05**；ALL **57** / M4 **10**（**DX21**） |
| 私有 Skill packs | 打包/验签/安装 API；space/publisher allowlist；落盘 `.ash/skills`；`make skill-pack-smoke`（**DX22**） |
| 单区域就绪 | `ASH_REGION` / `/readyz` + Scale `region`；[`single-region-ha.md`](../checklists/single-region-ha.md)（**DX23**） |
| 冻结 + 签字 | `v2.6-release-scope` 冻结；`make v2.6-signoff`（**DX24**） |

## 3. 不包含范围（本版本 Out）

- **完整 LSP 客户端**（gopls/tsserver 常驻守护 / hover / 跨文件引用）— 可进 v2.7  
- **E2B / 远程 microVM** 作为默认或硬依赖  
- 公网 Skill Marketplace、评分、计费、CDN  
- Active-Active 多区域、数据驻留合规产品化  
- 真实 embedding 硬依赖、Chroma/Milvus 适配器（仍沿用 v2.5 Vector POC）  
- 云 RDS / GitHub·ExecGo live 强制（P0 环境项不变）

## 4. 变更冻结规则

- 冻结后仅接受 **P0 缺陷**、**文档/门禁**、以及 Out 项的环境验收证据  
- 新表 DDL 必须同步 SQL rev + RLS + Doctor（若触及）  
- 破坏性 API 须 OpenAPI + `make openapi-check`  
- 打 **`v2.6.0` tag** 前须完成本文件签字表 + `make v2.6-signoff` 绿
