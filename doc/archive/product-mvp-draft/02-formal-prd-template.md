# 正式 PRD 模板填充版（MVP）

## 1. 需求概述
- 产品名称：Devix / ASH AI Platform（过渡阶段）
- 目标：打通需求、开发、测试、发布、复盘流程，提升软件交付效率与质量。

## 2. 业务目标与成功标准
- Copilot 周活渗透率 >= 60%
- AI 建议采纳率 >= 30%
- CI 一次通过率提升 >= 10%
- MTTR 降低 >= 15%
- 反馈闭环处理率 >= 70%

## 3. 用户与场景
- 目标用户：工程师、技术负责人、平台管理员
- 场景：
  - 需求快速落码
  - CI 失败智能诊断
  - 知识增强开发
  - 团队协作闭环

## 4. 范围定义
- In Scope：Auth、Repo/CI/Artifact、Copilot、Agent+Memory+KBase、反馈体系
- Out Scope：复杂组织权限模型、开放插件市场、全自动发布治理

## 5. 功能需求（FR）

### FR-01 Auth
- 支持 SSO、角色权限、审计日志
- 验收：权限边界正确，审计可查询

### FR-02 Repo/CI/Artifact
- 代码、流水线、制品三方信息可追溯
- 验收：提交可关联 CI 和制品结果

### FR-03 Copilot
- 生成、解释、修复建议
- 验收：建议可采纳/拒绝并记录

### FR-04 Agent + KBase + Memory
- 可检索知识、复用记忆、跨会话继承
- 验收：二次任务质量可见提升

### FR-05 产品空间协作
- 任务分派、成员协作、沉淀共享
- 验收：团队可在空间内完成任务闭环

### FR-06 MCP / Skill
- 白名单接入、启停、版本管理、日志记录
- 验收：扩展可控可追溯

### FR-07 Feedback
- AI 输出反馈采集、分类、看板
- 验收：闭环状态可见

## 6. 用户故事样例
- 作为开发者，我希望在 CI 失败后快速获得原因摘要和修复建议。
- 作为负责人，我希望看到采纳率与质量趋势以评估 ROI。
- 作为管理员，我希望可控管理扩展权限与审计记录。

## 7. 非功能需求
- 安全：RBAC、审计、脱敏
- 性能：核心响应时延可控
- 稳定：可用性 >= 99.9%
- 可观测：日志、指标、追踪齐全

## 8. 里程碑建议
- M1（2周）：需求冻结 + 方案评审
- M2（4周）：核心能力开发
- M3（2周）：联调灰度
- M4（1周）：上线复盘
