# AI 产品需求调研文档（基于参考截图）

## 1. 文档信息
- 文档类型：产品需求调研（PRD 前置）
- 调研对象：Aone Command Line / Devix 文档中心
- 版本：v0.1

## 2. 调研背景与目标
- 目标平台定位为 AI Native 研发平台，覆盖代码、测试、发布、协作、反馈全流程。
- 目标是通过 Agent + Copilot + MCP 工具链接入提升研发效率与交付质量。

## 3. 产品定位（初步）
- 一句话定位：面向研发团队的一站式 AI 工程平台。
- 目标用户：研发工程师、技术负责人、平台工具团队。

## 4. 模块能力盘点

### 4.1 平台能力层（Aone Command Line）
- Auth：统一认证、SSO、权限控制
- Repo：代码仓库、分支与 MR 协作
- CI：构建/测试/流水线编排
- Artifact：制品归档与版本追踪
- App：应用创建与运行配置
- Project：项目空间与资源组织
- KBase：知识库检索与上下文增强
- Memory：会话与偏好记忆
- Link：外部系统连接
- Skill：技能模板与复用
- MCP：外部工具协议接入
- Staff：团队协作治理
- Feedback：反馈回流闭环

### 4.2 产品入口层（Devix）
- 我的助理：个人 AI 工作台
- 产品空间：团队协作与多 Agent 协同
- Copilot：IDE 内编码辅助
- Agent 扩展：自定义能力扩展

## 5. 用户需求分析

### 5.1 工程师
- 需求：减少重复劳动、减少工具切换、提高交付速度
- 痛点：信息分散、上下文缺失、修复链路长

### 5.2 技术负责人
- 需求：可量化效率提升与质量稳定
- 痛点：流程可见性不足、知识沉淀弱

### 5.3 平台团队
- 需求：标准化接入与低成本扩展
- 痛点：系统孤岛、接口不统一

## 6. 关键业务场景（MVP）
- 需求到交付：需求输入 -> 代码建议 -> 提交 -> CI -> 制品归档
- 故障定位：失败日志聚合 -> 原因归因 -> 修复建议
- 知识增强：规范检索 -> 历史经验复用 -> 结果沉淀
- 协作闭环：任务分发 -> 执行反馈 -> 策略优化

## 7. 功能优先级建议
- P0：Auth、Repo/CI、Copilot 基础能力、KBase/Memory、Feedback
- P1：MCP 接入管理、Skill 复用、多 Agent 协同
- P2：组织级治理与跨项目智能推荐

## 8. 非功能需求
- 安全：SSO、RBAC、审计日志、敏感信息脱敏
- 性能：Copilot 快速响应、Agent 执行状态可观测
- 扩展：MCP 与 Skill 插件化
- 稳定：任务幂等、失败重试、链路追踪

## 9. 核心指标建议
- 效率：需求到首版时间、MR 周期、MTTR
- 质量：CI 一次通过率、回滚率、缺陷复开率
- AI 价值：采纳率、任务成功率、自动化覆盖率

## 10. 风险与待确认
- 截图信息有限，模块边界需结合真实系统验证
- Memory 与 KBase 数据边界、隐私策略需明确
- Agent 扩展开放策略（白名单/沙箱）需明确
