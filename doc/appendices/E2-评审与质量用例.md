# 附录 E2：评审与质量用例（v7） / Appendix E2: Review & quality cases (v7)

> Doctor 只回答「ASH 能否运行」。交付质量、引用门禁、记忆对错归 **评审 / `QUALITY` 套件**。  
> Doctor answers runtime health only. Delivery quality, citation gates, and memory correctness belong to **review / the `QUALITY` suite**.

## 1. Doctor 套件分层 / Doctor suite layers

| 套件 / Suite | 职责 / Role |
|-------------|-------------|
| `BOOT` | 配置、场景目录、产物存储、插件 ABI、OpenAPI、readyz |
| `TR0`–`TR3` / `M*` / `ALL` | 运行时可回归（已迁出质量用例） |
| `QUALITY` | TR0-01 / TR0-04 / TR0-06 / TR1-02 / TR1-03 / TR1-06 / TR3-04 |

`ash doctor --suite BOOT` 是默认启动诊断。质量门禁用 `ash doctor --suite QUALITY` 或评审队列。  
`ash doctor --suite BOOT` is the boot probe. Quality gates use `QUALITY` or the review queue.

## 2. 与评审对象的关系 / Relation to review objects

| 质量信号 / Signal | 评审对象 / Review kind |
|------------------|------------------------|
| 模板绑定与 Pass^k | `agent_template` |
| Harness Activate | `harness_profile` |
| 记忆候选 / 巩固 / 遗忘 | `memory_record` |
| 产物与运行样本 | `artifact` / `run_sample` |

进程内队列见 `internal/review`；持久化表见 `review_items`（G01）。  
In-process queue: `internal/review`. Persisted rows: `review_items` (G01).
